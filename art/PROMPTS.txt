LIVELOT UI IMAGES: 7 PROMPTS
=============================

How to use
- Paste each prompt below into ChatGPT or Gemini (one chat for all 7, so the style matches).
- Each prompt makes ONE image: a sheet of 6 icons (the last one has 4).
- Save the 7 images as sheet-1.png ... sheet-7.png (any image type is fine) into:
    /home/sm/cod/LiveLot/art/sheets/
  then tell Claude. Claude cuts them up, cleans the backgrounds and puts every icon in the app.
- If one icon on a sheet comes out wrong, just ask the chat to redo that sheet.
- Sheets 1-3 are already done (Gemini). In ChatGPT, attach art/sheets/sheet-2.jpg with the first prompt
  and add: "Match the style of the attached image exactly." so the new sheets look the same.
